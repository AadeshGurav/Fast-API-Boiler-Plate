API Documentation

Authentication Flow

  1. Register: POST to /auth/register with user details
  2. Login: POST to /auth/login with username/password
  3. Get Token: Response includes session token for API calls
  4. Use Token: Include token in Authorization header: Bearer <token>

RBAC System

  • Roles: Hierarchical permissions (admin > manager > user > guest)
  • Permissions: Resource-based access control (resource:action)
  • Groups: Collections of roles for easier management
  • Temporary Permissions: Time-limited access grants

Example API Calls
